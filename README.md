# OTA updates for Lenovo TB-X704F (unofficial LineageOS)

`X704F.json` is read by the LineageOS Updater app on the device
(`lineage.updater.uri`). The install packages are attached to the
[releases](../../releases) of this repository.

Builds are signed with private release keys. They install only on top of
builds signed with the same keys.

Sources: [device](https://github.com/knaepel/android_device_lenovo_X704F),
[common](https://github.com/knaepel/android_device_lenovo_msm8953-common),
[kernel](https://github.com/knaepel/android_kernel_lenovo_msm8953).
